1. Starting the System

Step 1 — Start Docker Desktop

Open the Docker Desktop app on your Mac. Wait until the whale icon in the menu bar stops animating (30–60 s).

Step 2 — Build & launch

2. Testing Checklist

2.1 Home Page

  • Opens at http://localhost:3000
  • Shows 6 real products from backend (not hardcoded)
  • "Add to Cart" buttons work
  • "View All Products" link goes to /products
  • Promo banner links to /promotions

2.2 Registration (IPOS-PU-Members)

  • Click "Create Account" on login page
  • Only email field shown (no password — it's auto-generated)
  • Info text says "A password will be generated and sent to your email"
  • Click "Register" — success message appears
  • Check email inbox for generated password
  • If email doesn't arrive, check backend logs (docker-compose logs backend)

2.3 First Login + Forced Password Change

  • Sign in with email + generated password
  • Password change screen appears automatically
  • Enter old password + new password + confirm
  • After changing, redirected to home page
  • Log out and log in again with new password — no forced change

2.4 Products Page (IPOS-PU-SALES)

  • Go to /products
  • Products load with prices in £
  • Category filtering works (1, 2, 3, 4)
  • Search by keyword works (e.g. "para" → Paracetamol)
  • "Add to Cart" works
  • Stock quantities shown

2.5 Shopping Cart + Checkout

  • Go to /cart — items show with correct prices
  • Adjust quantities (+/−), remove items
  • Fill in delivery address
  • Fill in card details (type, first 4, last 4, expiry MM/YY)
  • Click "Place Order" — success message
  • Cart clears
  • Check email for order confirmation

2.6 Purchase History

  • Go to /purchase-history
  • Order(s) appear with status "received"
  • Click to expand — items, quantities, prices shown
  • Filter by status works

2.7 Order Status Update (via terminal)

# Update to Dispatched
curl -X PUT http://localhost:8080/api/orders/1/status \
  -H "Content-Type: application/json" \
  -d '{"status":"Dispatched"}'

# Update to Delivered
curl -X PUT http://localhost:8080/api/orders/1/status \
  -H "Content-Type: application/json" \
  -d '{"status":"Delivered"}'
  • Refresh purchase history — status updates correctly

2.8 Promotions — Merchant Creates Campaign

First, make your user a merchant:

curl -X POST http://localhost:8080/merchant/response \
  -H "Content-Type: application/json" \
  -d '{"email":"YOUR_EMAIL_HERE"}'
  • Log in with that email
  • Go to /promotions — Merchant Dashboard appears
  • Click "+ New Campaign"
  • Enter name, start date, end date
  • Select products and set discount %
  • Click "Create Campaign" — campaign appears in table
  • Click campaign row to expand — shows items + conversion tracking
  • Cancel a campaign — it disappears

2.9 Promotions — Public View

  • Log out (or use incognito window)
  • Go to /promotions
  • Active campaigns show as cards
  • Click a campaign → items with discounted prices appear
  • "Add to Cart" works with discounted price

2.10 Reports (IPOS-PU-RPT)

  • Log in as merchant, go to Merchant Dashboard → "Reports" tab
  • Sales report shows real order data
  • Change date range, click "Generate"
  • Totals match at bottom

API test:

# Sales report
curl "http://localhost:8080/api/reports/sales?startDate=2026-01-01&endDate=2026-12-31"

# Campaign report
curl "http://localhost:8080/api/reports/campaigns?startDate=2026-01-01&endDate=2026-12-31"

# Engagement / conversion report

2.11 Merchant Application → SA

curl -X POST "http://localhost:8080/merchant/application?email=test@example.com"

# View pending applications
curl http://localhost:8080/merchant/applications

  -H "Content-Type: application/json" -d '{"email":"test@example.com"}'

# SA rejects

  -H "Content-Type: application/json" -d '{"email":"test@example.com"}'

3. Demo Day Script (16 April)

3.1 Before the demo — Load demo data

Save this as demo-setup.sh and run it after starting Docker:

#!/bin/bash
API="http://localhost:8080"

echo "=== 1. Register demo user ==="
curl -s -X POST "$API/auth/signup" \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@pharmacy.com","password":"demo123"}'

echo -e "\n=== 2. Make demo user a merchant ==="
curl -s -X POST "$API/merchant/response" \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@pharmacy.com"}'

echo -e "\n=== 3. Place demo orders ==="
curl -s -X POST "$API/api/orders" \
  -H "Content-Type: application/json" \
  -d '{
    "userEmail":"demo@pharmacy.com",
    "deliveryAddress":"3, High Level Drive, Sydenham, SE26 3ET",
    "cardType":"VISA","cardFirstFour":"4242",
    "cardLastFour":"1234","cardExpiry":"12/27",
    "items":[{"productId":1,"quantity":10},
             {"productId":2,"quantity":5},
             {"productId":3,"quantity":20}]
  }'

echo -e "\n=== 4. Update order status ==="
curl -s -X PUT "$API/api/orders/1/status" \
  -H "Content-Type: application/json" \
  -d '{"status":"Dispatched"}'

echo -e "\n=== 5. Create promotion ==="
curl -s -X POST "$API/promo/create" \
  -H "Content-Type: application/json" \
  -d '{"name":"Spring Sale","start":"2026-04-01","end":"2026-04-30"}'

curl -s -X POST "$API/promo-product/add" \
  -H "Content-Type: application/json" \
  -d '{"productId":1,"discount":20,"promotionName":"Spring Sale"}'

curl -s -X POST "$API/promo-product/add" \
  -H "Content-Type: application/json" \
  -d '{"productId":2,"discount":15,"promotionName":"Spring Sale"}'

curl -s -X POST "$API/promo-product/add" \
  -H "Content-Type: application/json" \
  -d '{"productId":5,"discount":10,"promotionName":"Spring Sale"}'

echo -e "\n=== 6. Register non-commercial customer ==="
curl -s -X POST "$API/auth/register" \
  -H "Content-Type: application/json" \
  -d '{"email":"customer@test.com"}'

echo -e "\n\n=== DONE ==="
echo "Merchant: demo@pharmacy.com / demo123"
echo "Frontend: http://localhost:3000"
chmod +x demo-setup.sh
./demo-setup.sh

4. Troubleshooting

ProblemFix
"Cannot connect to Docker"Open Docker Desktop app, wait for it to start
Backend keeps restartingdocker-compose logs backend — usually MySQL isn't ready, wait 30s
Schema errors / table missingdocker-compose down -v && docker-compose up --build
Frontend not loadingdocker-compose logs frontend — check npm errors
Email not sendingCheck backend logs. Emails are logged to console regardless.
Port 8080 in uselsof -i :8080 → kill the process
Port 3000 in uselsof -i :3000 → kill the process
Products page emptyCheck insert_products.sql ran. Try: curl http://localhost:8080/api/products
CA offline warning in logsNormal if IPOS-CA isn't running. PU uses its local cache.
